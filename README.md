# 🎨 Color Palette Generator

A simple and interactive web application that generates random HEX color codes and displays a live color preview.

## ✨ Features

- Generate random colors with one click
- Display HEX color codes
- Preview colors instantly
- Click the HEX code to copy it to the clipboard
- Simple and responsive UI

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite
- Clipboard API
